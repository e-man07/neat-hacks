# Funnels

A funnel measures how many users complete a sequence of steps.

## Conversion window

By default a user must finish all steps within 7 days. You can set the conversion window anywhere from 1 minute to 90 days.

## Step limit

Funnels support up to 20 steps. Each step can filter on event properties.

## Holding constant

Hold a property constant (for example `device`) to only count users whose property value stays the same across every step.
