# Deleting data

## Delete a user (GDPR)

Submit a deletion request with the user's distinct ID from **Privacy → Deletion requests** or the Privacy API. Lumen deletes the user's events from all projects within 30 days and sends a confirmation email when done.

## Delete events by name

Admins can hide an event name immediately. Permanently deleting all events with a given name is irreversible and takes up to 7 days.

## Delete a project

Deleting a project removes all of its data after a 14-day grace period, during which the owner can restore it.
