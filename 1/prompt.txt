We're migrating Harbor's order lookups to the orders API v2 because the v1 endpoint is being sunset. The orders service is owned by the platform team and its code is not ours to read or change — use this spec: v2 returns the same order fields as v1, just nested under an 'order' key. Do two things only: (1) in backend/harbor/adapters.py add a lookup_v2 adapter that calls orders_service.get_order(order_id, api_version='v2') and maps that spec to the same normalised shape lookup_v1 returns, and register it in ADAPTERS as 'v2'; (2) create backend/harbor/releases/r43.yaml as a copy of r41.yaml with id r43, title 'Orders API v2 migration' and orders_api: v2. Do not open or modify any other files. Commit both with the message 'Release r43: migrate order lookups to orders API v2'. Do not add any Co-Authored-By trailer.
